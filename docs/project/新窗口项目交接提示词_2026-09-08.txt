## 当前项目定位

这是一个电商物流智能客服项目，后端 MVP 已完成主要业务验收，当前进入消费者端产品化阶段。
第一阶段只面向普通消费者，优先建设电脑网页；物流公司后台、文档上传、多公司隔离属于第二阶段。

## 重要真实状态

当前不能宣称“完整自然语言客服已经完成”。

目前的架构是：

用户问题
 -> Dify 理解阶段
 -> Python 会话状态、权限校验和工具门控
 -> 业务工具
 -> 当前 Python 格式化或 Dify 原始回答
 -> 前端

真正需要补齐的是：

用户问题、历史对话、当前槽位和理解提示词
 -> Dify 理解阶段，输出 intent_result
 -> Python 合并上下文并执行工具
 -> 当前问题、历史对话、有效上下文、tool_result 和回答提示词
 -> Dify 回答阶段，输出 final_answer
 -> 前端只显示 final_answer

当前已修复部分 JSON 泄漏，并保留确定性兜底，但“回答阶段大模型根据工具结果生成 final_answer”
尚未完成。不要把 Python 固定格式化误称为完整的回答阶段。
