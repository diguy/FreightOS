## 二、顺丰速运

### 2.1 官方页面

- 官方收寄标准查询页：<https://www.sf-express.com/chn/sc/accept-query>
- 顺丰官网服务查询中包含“运费时效”“服务范围”“收寄标准”等入口。

### 2.2 禁寄和限寄规则

顺丰官方收寄标准页面列出的进出口件禁止或限制寄递物品包括：

- 武器、仿真武器、弹药、管制器具及爆炸物品
- 易燃烧性物品、易爆炸性物品
- 氧化剂和过氧化物
- 毒品及吸毒工具
- 非正当用途的麻醉药品和精神药品
- 非正当用途的易制毒化学品
- 毒性物质
- 生化制品
- 传染性、感染性物质
- 腐蚀性物质
- 放射性物质
- 危害国家安全和社会稳定的非法出版物、印刷品、音像制品等宣传品
- 涉及国家秘密的文件、资料及其他物品
- 间谍专用器材
- 伪造或变造的货币、有价证券、证件、公章等非法伪造物品
- 货币和有价证券
- 侵犯知识产权和假冒伪劣物品
- 动植物，尤其是濒危野生动物、植物及其制品
- 来自疫区或可能传播疾病、危害人畜健康的食品、药品或其他物品
- 烟草和烟草制品、酒
- 贵重物品，例如艺术品、古董、宝石和黄金等贵重金属
- 其他法律法规规定的违禁品

顺丰官方还说明，以下情况也可能被拒绝寄递或暂停寄递：

- 没有提供寄件人和收件人详细联系信息
- 没有用适合寄递的方式进行描述、分类、包装和贴标签
- 没有提供必要凭证
- 物品或包装特性可能危及运输工具或人员安全
- 顺丰根据经济或操作因素判断不适合寄递

### 2.3 知识库问答

```text
问题：哪些物品不能通过顺丰寄送？
答案：顺丰官方收寄标准列出的禁止或限制寄递物品包括武器弹药、爆炸物、易燃易爆物品、毒品、危险化学品、传染性或感染性物质、腐蚀性物质、放射性物质、货币和有价证券、假冒伪劣物品、部分动植物及其制品、烟草和酒、贵重物品以及其他法律法规规定的违禁品。具体是否可以寄送，应结合寄件地、目的地和物品情况向顺丰官方确认。

问题：为什么有些包裹会被顺丰拒收？
答案：如果包裹缺少寄件人或收件人详细联系信息，物品没有正确描述、分类、包装或贴标签，缺少必要凭证，或物品存在安全、经济或操作风险，顺丰可能拒绝或暂停寄递。
```

## 三、圆通速递

### 3.1 官方页面

- 国内运费查询页：<https://www.yto.net.cn/ytoExpress/querySupport/standardPrice/>
- 圆通官网提供“运费时效查询”“服务范围查询”和“禁限禁运品（公告）”入口。

### 3.2 国内计费规则

圆通官方国内运费查询页公开的运费说明：

1. 快件采用首重和续重计价方式。
2. 实际重量和体积重量比较后，取较大值作为计费重量。
3. 体积重量计算公式：

```text
体积重量 = 长（cm）× 宽（cm）× 高（cm）÷ 8000
```

4. 首重不足 1 kg，按 1 kg 计算。
5. 续重以 0.1 kg 为计费单位，不足 0.1 kg 按 0.1 kg 计算。
6. 重量包含包装后的快件整体重量。
7. 运费计算结果以元为单位，四舍五入取整。
8. 以上规则可能因服务、产品或所在地区不同而产生差异，应以圆通查询结果、当地快递员或客服确认结果为准。

### 3.3 知识库问答

```text
问题：圆通快递怎么计算运费？
答案：圆通国内快件采用首重和续重计价方式。实际重量和体积重量比较后，取较大值作为计费重量。体积重量等于长、宽、高的厘米数相乘后除以8000。首重不足1千克按1千克计算，续重以0.1千克为计费单位，不足0.1千克按0.1千克计算。最终费用可能因服务、产品和地区不同而变化，应以圆通官方查询结果为准。

问题：圆通体积重量怎么算？
答案：圆通官方国内运费说明中的体积重量公式是：长（cm）×宽（cm）×高（cm）÷8000。

问题：圆通快件重量是否包含包装？
答案：圆通官方说明，计费重量中的重量包含包装后的快件整体重量。

问题：圆通偏远地区会不会增加费用？
答案：费用可能因服务、产品或所在地区不同而有所差异。具体是否产生附加费用，应在圆通官方运费查询中输入始发地、目的地、重量和体积后确认。
```

### 3.4 时效和特殊区域

圆通官网提供国内运费时效查询，需要填写：
