顺丰

一、运费计算基于以下计费规则：

1\. 计费重量规则

计费重量指包裹的总重量，包括货物本身、包装材料及必要的辅助物品（如冰袋、泡沫箱等）

2\. 体积重量计算方法

托寄物的计费重量取体积重量与实际重量两者之间的较大值，若为子母件，则将每件的计费重量进行汇总后计算总运费，其中，体积重量的计算方法为：  
**【顺丰特快】**  
中国内地大部分流向互寄，体积重量=长（cm) x 宽（cm) x 高（cm) ÷6000；

黑/吉/辽/内蒙部分省（自治区）内及互寄流向的体积重量=长（cm) x 宽（cm) x
高（cm) ÷12000。

【 **顺丰标快** 】

  中国内地大部分流向互寄，当实际重量30kg以下，体积重量 = 长 (cm)× 宽
(cm)× 高
(cm)÷12000（部分优惠顺丰标快产品的体积重量=长(cm)x宽(cm)x高(cm)÷6000，体积重量计费规则有变化，具体以实际显示计价为准）
；当实际重量30kg及以上，体积重量 = 长 (cm)× 宽 (cm)× 高 (cm)÷6000。

 
西藏昌都市与西藏自治区内其他城市互寄以及西藏昌都市与海南三沙市互寄，体积重量
= 长 (cm)× 宽 (cm)× 高 (cm)÷6000。

【 **顺丰卡航 / 冷运标快** 】 体积重量 = 长 (cm)× 宽 (cm)× 高 (cm)÷6000
；

【 **冷运大件** 】 体积重量 = 长 (cm)× 宽 (cm)× 高 (cm)÷3000 ；

**【港澳台（服务）】   **体积重量 = 长 (cm)× 宽 (cm)× 高 (cm)÷6000；

**【国际快递（服务）】** 体积重量 = 长 (cm)× 宽 (cm)× 高 (cm) ÷5000；

**【顺丰半日达】**体积重量 = 长 (cm)× 宽 (cm)× 高 (cm) ÷6000；

其他产品计算方法请致电 95338 或咨询当地收派员。

3\. 计费重量小数点进位处理方式

**【中国内地互寄业务】** 中国内地互寄业务：10kg以下，续重以0.1kg为计重单位；10-100kg，续重以0.5kg为计重单位；100kg及以上，四舍五入取整数。

**【港澳本地业务】** 续重以0.5kg为计重单位，不足 0.5kg，按0.5kg计。

**【中国内地始发至港澳台业务】**100kg以下 ,
续重以0.5kg为计重单位，不足0.5kg ，按0.5kg 计；
100kg及以上，以1kg为计重单位，小数点后尾数大于零的，向上进位至下一个1kg
。

**【中国内地始发至海外国家及地区业务】**20kg以下 ,
续重以0.5kg为计重单位，不足0.5kg，按
0.5kg计；20kg及以上，以1kg为计重单位，小数点后尾数大于零的，向上进位至下一个1kg。

4\. 运费计算结果处理方式

运费计算结果按四舍五入取整数值；

\-
运费不含任何增值服务费用，以上运费计费规则可能因产品或所在地区不同而有所差异，详情致电
95338 或咨询当地收派员。

**二、保价、燃油附加费计算结果处理方式**  
-
保价、燃油附加费（中国香港、澳门、台湾地区至中国内地、中国内地及港澳台地区至海外国家、中国港澳台地区互寄）；计算结果按四舍五入取整【取货币单位元的整数值】；  
-
燃油附加费（中国内地互寄、中国内地至港澳台地区），计算结果按四舍五入取一位小数【取货币单位元后一位小数】。

 

**一、时效标准**

预计时效因节假日、天气、交通管控、资源等原因不同日期时间查询会有所差异，具体以系统实时返回为准。
