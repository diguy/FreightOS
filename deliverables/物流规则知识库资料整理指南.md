# 电商物流 FAQ 知识库资料整理指南

## 一、目标

为 Dify 的“电商物流 FAQ”知识库准备可靠、结构清晰、便于检索的物流规则资料。

重点整理以下四类内容：

1. 配送时效说明
2. 禁寄品清单
3. 计费规则
4. 特殊区域说明

资料应优先来自快递公司官方网站、官方服务协议、官方规则页面或官方公开文件。

## 三、需要整理的知识内容

### 1. 配送时效说明

保留以下内容：

- 普通地区的预计配送时间
- 偏远地区可能增加的配送时间
- 节假日、天气、物流高峰对时效的影响
- 不同服务类型的时效差异
- 时效承诺的适用条件
- 物流信息更新延迟的说明

建议整理格式：

```text
问题：普通地区通常多久送达？
答案：填写官方规则中的配送时效。

问题：偏远地区配送需要多久？
答案：填写官方规则中的特殊时效说明。

问题：哪些情况可能导致配送延迟？
答案：填写官方规则中关于天气、节假日、物流高峰或不可抗力的说明。
```

### 2. 禁寄品清单

保留以下内容：

- 易燃易爆物品
- 危险化学品
- 枪支弹药
- 管制刀具
- 毒害物品
- 放射性物品
- 违法物品
- 法律法规禁止运输的其他物品
- 快递公司明确限制或禁止收寄的物品

注意：

- 不要自行扩展官方清单没有明确提到的物品。
- 对“禁止寄送”和“限制寄送”进行区分。
- 如果不同快递公司的规则不同，应分别标注快递公司。

建议整理格式：

```text
问题：哪些物品禁止寄送？
答案：根据官方禁寄品规则，禁止寄送的物品包括：填写官方清单。

问题：哪些物品需要限制条件才能寄送？
答案：填写官方规则中的限制寄送物品、包装要求或申报要求。
```

### 3. 计费规则

保留以下内容：

- 按重量计费的规则
- 按体积计费的规则
- 首重和续重的说明
- 不同地区的价格差异
- 不同服务类型的价格差异
- 偏远地区附加费用
- 超长、超重或特殊包装费用
- 最终费用以官方查询结果或下单页面为准的说明

建议整理格式：

```text
问题：快递费用通常根据什么计算？
答案：填写官方计费因素，例如重量、体积、收货地区和服务类型。

问题：什么是首重和续重？
答案：根据官方资费规则解释首重和续重。

问题：偏远地区是否可能产生额外费用？
答案：根据官方规则填写偏远地区附加费用说明。
```

### 4. 特殊区域说明

保留以下内容：

- 偏远地区
- 港澳台地区
- 西藏、新疆等特殊区域
- 海岛地区
- 无法派送或需要中转的地区
- 特殊区域的时效变化
- 特殊区域的费用变化
- 特殊区域的收寄限制

建议整理格式：

```text
问题：偏远地区配送有什么不同？
答案：填写官方关于配送时效、费用和派送范围的说明。

问题：特殊地区是否需要增加运费？
答案：填写官方附加费用规则。

问题：哪些地区可能无法直接派送？
答案：填写官方派送范围或限制说明。
```

## 四、网页或 PDF 清洗要求

### 应保留

- 规则正文
- 适用范围
- 配送时效
- 计费方式
- 禁寄和限寄物品
- 特殊区域说明
- 规则生效条件
- 官方更新时间

### 建议删除

- 页眉
- 页脚
- 重复的公司名称
- 页面编号
- 无意义的条款编号
- 重复目录
- 广告内容
- 大段免责声明
- 与物流 FAQ 无关的法律说明
- 下载按钮文字
- 网页导航文字

### 清洗原则

1. 不改变官方规则原意。
2. 不自行推断官方没有说明的内容。
3. 不把第三方解读写成官方规则。
4. 不混合不同快递公司的规则。
5. 每条规则尽量包含适用对象和限制条件。
6. 资料中应记录来源公司和来源名称。
7. 如果规则可能发生变化，应记录查询日期。

## 五、推荐的知识库文档结构

可以按快递公司分别创建文档：

```text
电商物流 FAQ/
├── 顺丰物流规则.md
├── 圆通物流规则.md
├── 京东物流规则.md
└── 通用物流 FAQ.md
```

也可以按知识主题创建文档：

```text
电商物流 FAQ/
├── 配送时效.md
├── 禁寄品规则.md
├── 计费规则.md
└── 特殊区域说明.md
```

当前学习项目建议先按快递公司分别整理，后续更容易定位来源和处理不同公司的规则差异。

## 七、导入 Dify 前检查清单

- [ ] 内容来自官方页面或官方文件

- [ ] 已保留规则适用范围
- [ ] 已区分禁止寄送和限制寄送
- [ ] 已区分不同快递公司的规则
- [ ] 已记录来源名称
- [ ] 已记录查询日期
- [ ] 没有把推测内容写成官方规则
- [ ] 文档使用清晰的问题和答案结构
- [ ] 导入后可以通过关键词检索到目标规则
